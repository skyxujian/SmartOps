## 首次登录

1. 输入“首次登录”私密文件中的账号邮箱与临时密码。
2. 系统要求先修改临时密码。输入当前密码，再输入两次新密码。
3. 新密码需为 12–128 个字符，不能与旧密码相同。建议使用密码管理器保管。
4. 保存后进入工作台。修改后请删除初始登录文件。

首个管理员为 `admin@smartops.local`，它只作为登录标识，不会自动接收邮件。当前没有开通邮件通知或邮件找回密码。

## 提交报修

员工无需登录，打开报修入口，填写科室、类型、标题、描述、联系方式和可选备注。标题至少 3 个字符，描述至少 5 个字符。

提交成功后会显示完整工单编号，请复制保存。网络超时后在同一页面重试，系统会防止同一次请求重复写入；刷新页面或成功后再次填写，将视为新工单。

请勿在描述中填写密码、验证码等敏感信息。工单描述和联系方式只有已登录管理员能查看，未开放公开工单查询。

## 查看和处理工单

登录后打开“工单管理”。每页 20 条，可按标题、科室、完整编号搜索，也可筛选状态。

点击“查看详情”，可查看完整编号、科室、类型、描述、联系方式、备注及提交与更新时间。选择处理状态并点击“保存状态”：

- 待处理：尚未开始。
- 处理中：正在跟进。
- 已解决：问题已处理完成。
- 已关闭：本次工单结束。

状态更新会保存操作审计记录。当前版本未包含工程师分配、处理评论、附件、通知或消息推送。

## 新增与删除管理员

打开“账号管理”，填写姓名、邮箱和至少 12 个字符的临时密码，点击“添加管理员”。通过可信渠道将账号和临时密码交给本人。新账号首次登录必须修改密码。

所有新增账号均拥有完整管理员权限，包括查看全部工单、修改状态和管理其他管理员。请仅为可信的运维人员创建。

点击目标账号的“删除”并确认后，该账号及其密码记录会被删除，已有会话立即失效。工单不会随账号删除。不能删除当前登录账号，也不能删除最后一位可用管理员。

## 修改密码与退出

点击“修改密码”，输入当前密码及两次新密码。修改后其他设备会话失效，当前设备使用新会话。使用完毕后点击“退出登录”。会话有效期为 8 小时。

## 数据保存位置

新版工单写入 Neon 免费数据库 `smartops-db`。正式工单在 `smartops.tickets`，预览在 `smartops_preview.tickets`。工单不会写入 GitHub 或浏览器本地存储。

账号、密码哈希和会话位于对应空间的 `user`、`account`、`session` 等表。密码不明文保存；`audit_log` 保存账号操作和工单状态变更记录。数据库凭据与会话签名密钥只在服务端受保护配置中保存。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 登录失败 | 检查邮箱和密码；多次失败后等待约一分钟再试。 |
| 登录后无法进入工单页 | 首次登录先修改临时密码。 |
| 找不到刚提交的工单 | 清空搜索和状态筛选，确认使用新版入口，并保留完整编号交给负责人核对。 |
| 忘记密码 | 联系另一位管理员删除旧账号后重新添加；仅有一个账号时，由系统负责人在服务端恢复，不能从前端绕过认证。 |
| 提交超时 | 原页面重试可防止同一次请求重复写入；不要立即刷新后重新填报。 |
| 服务暂时不可用 | 稍后重试；负责人检查 Vercel 日志、Neon 服务和免费额度。第一次请求可能因冷启动较慢。 |

## 维护和回退

Vercel 项目名仍为 `yangmao-radar`，GitHub 仓库已改名为 `skyxujian/SmartOps`。本版本使用明确绑定项目的部署工具发布；自动 Git 部署连接仍显示旧名称，不应据此认定推送一定会上线。

数据库是 Free 套餐，未开通付费升级。负责人应定期检查服务商用量并导出备份，免费服务的恢复能力和额度以当时规则为准。不要将 `.env.local`、临时登录文件或备份上传到公开仓库。

回退时在 Vercel 选择已知可用部署并恢复域名指向。网站回退不恢复或删除数据库内容。若回退至旧报修页面，新提交会再次发往原 Worker；回退前先通知使用者并备份新版数据。
